# صندوق ورودی فایل

سرویس کوچک و بدون وابستگی برای فرستادن فایل‌های حجیم (ویدیو، تصویر، صدا) به
داخل این محیط؛ چون گفتگو فایل بزرگ را نمی‌پذیرد.

```bash
cd inbox
./start.sh                 # http://0.0.0.0:8787
INBOX_PORT=9000 ./start.sh # پورت دیگر
./setup-ffmpeg.sh          # ffmpeg قابل‌حمل برای مدت/ابعاد/نما/نسخهٔ سبک
```

- آپلود تکه‌تکه (۴ مگابایت) و قابل‌ادامه؛ قطع اتصال، آپلود را از همان بایت ادامه می‌دهد.
- سقف هر فایل ۲۰۰ مگابایت؛ پسوندهای اجرایی رد می‌شوند.
- فایل‌ها در `inbox/uploads/` ذخیره می‌شوند (در گیت نیستند، ولی در snapshot محیط می‌مانند).
- برای ویدیوهای بزرگ‌تر از ۲۴ مگابایت یک نسخهٔ سبک ۷۲۰p و شش نمای پیش‌نمایش ساخته می‌شود.

## مسیرها

| مسیر | کار |
| --- | --- |
| `POST /api/new` | `{name,size,type}` → `{id}` |
| `PUT` یا `POST` `/api/chunk/:id?offset=N` | بدنهٔ خام تکه؛ آفست نادرست → `409` |
| `POST /api/done/:id` | نهایی‌سازی + ffprobe + نماها |
| `GET /api/state/:id` | بایت دریافت‌شده |
| `GET /api/files` | فهرست |
| `GET /files/:id` | فایل اصلی با Range |
| `GET /proxy/:id` | نسخهٔ سبک ۷۲۰p |
| `GET /frames/:id/01.jpg` | نما |
| `DELETE /api/files/:id` | حذف |

پس از رسیدن فایل، آن را به ویدیوی هیرو تبدیل کن:

```bash
npm run film:video -- inbox/uploads/<id>-clip.mp4
```
